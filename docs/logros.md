# Logros y rincones de GitHub

La meta: tocar todos los puntos del plan gratuito de GitHub, sin llevarlo al
límite, y que los logros salgan del trabajo real en la familia. Se tachan a
medida que aparecen en el perfil.

> Los umbrales son los publicados por GitHub a la fecha de escribir esto.
> GitHub cambia el catálogo de vez en cuando: si uno no aparece, revisar
> <https://github.com/DavidRodriguezSilva?tab=achievements> antes de insistir.

## 1. Logros (achievements)

| ✓ | Logro | Cómo se gana | Cómo lo sacamos en Dark4rest |
|---|---|---|---|
| [ ] | **Quickdraw** | Cerrar un issue o PR dentro de los 5 minutos de abrirlo | Abrir un issue de tarea pequeña en `dark4rest` y cerrarlo con el commit que la resuelve |
| [ ] | **YOLO** | Mergear un PR sin revisión | Primer PR de `dark4rest`, mergeado por ti mismo |
| [ ] | **Pull Shark** ×1 / ×2 / ×3 / ×4 | 2 / 16 / 128 / 1024 PRs mergeados | Trabajar con ramas y PR en vez de empujar a `main` (ver §3) |
| [ ] | **Galaxy Brain** ×1…×4 | 2 / 8 / 16 / 32 respuestas aceptadas en Discussions | Activar Discussions en las apps y responder dudas reales (también vale responder en repos ajenos, p. ej. whisper.cpp) |
| [ ] | **Starstruck** ×1…×4 | Un repo tuyo con 16 / 128 / 512 / 4096 estrellas | Llega con difusión (ver §4); no se fuerza |
| [ ] | **Pair Extraordinaire** ×1…×4 | 1 / 10 / 24 / 48 PRs mergeados con un commit coautorado | ⚠️ Requiere el trailer `Co-authored-by` de **otra persona**. Choca con la regla de no poner coautores; sólo tendría sentido con un colaborador humano real. Decisión tuya |
| [ ] | **Public Sponsor** | Patrocinar a alguien en GitHub Sponsors | Cuesta dinero (desde 1 USD/mes). Candidato natural: `ggml-org`, el motor de dark-owl. Opcional |
| [ ] | **Heart On Your Sleeve** | Reaccionar con ❤️ a algo | Por verificar si sigue activo |
| [ ] | **Open Sourcerer** | PRs mergeados en varios repos públicos | Por verificar si sigue activo; un PR aceptado a un proyecto ajeno lo acerca |
